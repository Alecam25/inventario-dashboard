# 📦 Sistema de Inventario - Restaurante

Sistema de gestión de inventario desarrollado con PHP y MySQL. Permite administrar insumos, controlar existencias y registrar movimientos de entrada y salida.

## 🚀 Funcionalidades

- ✅ Registro de insumos
- ✅ Edición y eliminación de productos
- ✅ Control de stock actual y stock mínimo
- ✅ Registro de movimientos (Entradas / Salidas)
- ✅ Dashboard con resumen de inventario
- ✅ Indicador visual de stock bajo

## 🛠️ Tecnologías utilizadas

- PHP
- MySQL
- HTML5
- CSS3
