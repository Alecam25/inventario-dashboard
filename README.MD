# 📦 Sistema de Inventario - Dashboard

Aplicación web desarrollada para la gestión de inventarios, orientada a negocios como restaurantes o empresas que manejan insumos y productos.

## 🚀 Características principales

* 📋 Gestión de productos (crear, editar, eliminar)
* 🗂️ Organización por categorías
* 🔄 Registro de movimientos (entradas y salidas)
* 📊 Visualización clara tipo dashboard
* 🧾 Control básico de inventario en tiempo real

## 🛠️ Tecnologías utilizadas

* PHP
* MySQL
* HTML5
* CSS3
* JavaScript

## 🎯 Objetivo del proyecto

Desarrollar un sistema funcional de inventario aplicando buenas prácticas de desarrollo web, bases de datos y estructura de proyectos reales.

## 🧠 Aprendizajes aplicados

* Conexión PHP + MySQL
* CRUD completo
* Organización modular del código
* Manejo de formularios y validaciones
* Diseño básico de interfaz de usuario


## ⚙️ Instalación

1. Clonar el repositorio:

   ```bash
   git clone https://github.com/Alecam25/inventario-dashboard.git
   ```

2. Mover el proyecto a tu servidor local (XAMPP, Laragon, etc.)

3. Importar la base de datos en MySQL

4. Configurar conexión en el archivo correspondiente

5. Ejecutar en el navegador:

   ```
   http://localhost/inventario-dashboard
   ```
